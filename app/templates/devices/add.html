{{ icon('plug') }} ESP32 Device ID MAC based

Copy the ID from the Arduino Serial Monitor. Leading dashes, spaces, and lowercase letters are normalised; the final 12 characters must be hexadecimal.

Generating the QR code does not register anything yet. The outlet is added when the QR link is opened by a signed-in account, or when you choose “Register on this computer”.

{{ icon('wifi') }} Same network required

The QR code points to this computer's local network address, never localhost. Your phone, the ESP32, and this server must be connected to the same Wi-Fi router.

  1. Find the ID. Open the Serial Monitor and wait for the network controller to print its Device ID.
  2. Generate. Paste the ID and create the QR link.
  3. Scan. Open the link on a phone signed in to your PowerAble account.
  4. Connect. The ESP32 heartbeat updates IP, relay, and hardware status.

{{ icon('shield') }} Device IDs are not secrets, but only registered IDs may send heartbeats.
