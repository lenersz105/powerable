About PowerAble

A web-based smart power outlet for local monitoring, relay control, energy awareness, and scheduling — built to work on a home network without cloud services.

Project purpose

Why this system exists.

PowerAble explores how an affordable smart outlet can report real electrical measurements, accept confirmed relay commands, and execute schedules entirely on a local network. The project is intended as a thesis prototype, not a commercial product.

  • Measure voltage, current, power, power factor, and energy.
  • Control four independent relay channels.
  • Store historical readings and device events in SQLite.
  • Provide scheduling and session energy limits.
  • Keep all essential functions available without internet access.

Architecture

Modular by design so each part can be understood and tested separately.

{{ icon('server') }} Flask routes Receive requests and return pages or JSON.
{{ icon('gauge') }} Services Energy math, device rules, QR pairing.
{{ icon('battery') }} SQLAlchemy models Users, outlets, readings, schedules, events.
{{ icon('wifi') }} Hardware channel Local network telemetry and commands.

Routes never talk to hardware directly. Services translate device messages into database records, and the dashboard only reads confirmed data.

Data honesty rules

Non-negotiable design constraints.

  • No random or simulated sensor values, ever.
  • Missing data is shown as missing, separate from a real zero.
  • A device is online only after verified communication.
  • Relay status changes only after hardware confirmation.
  • Energy cutoff requires valid, accumulated energy readings.
  • Test data, if used for layout previews, is clearly labelled.
