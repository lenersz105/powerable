What happens next

  1. A random pairing code is created. It contains no Wi-Fi password and no permanent device secret.
  2. A per-device API secret is generated. Only its SHA-256 hash is stored. The plaintext appears exactly once on the label response — write it into the Network ESP32 firmware.
  3. Print or scan the label. The device is not online merely because a label exists.
  4. The pairing code is single-use. Registering the outlet clears the hash, so the label stops working.
